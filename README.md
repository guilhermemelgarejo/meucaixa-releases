# MeuCaixa — instaladores e atualizações

Este repositório distribui os instaladores oficiais do MeuCaixa para Windows x64. O código-fonte é mantido em um repositório privado.

## Instalar

Acesse a [versão mais recente](https://github.com/guilhermemelgarejo/meucaixa-releases/releases/latest) e baixe o arquivo `MeuCaixa_<versão>_x64-setup.exe`.

A partir da versão `0.2.0`, o aplicativo verifica novas versões ao abrir e permite atualizar com sua confirmação. Quem usa uma versão `0.1.x` precisa instalar a `0.2.0` manualmente uma vez.

As assinaturas `.sig` e o arquivo `latest.json` acompanham os instaladores para que o MeuCaixa verifique a autenticidade das atualizações.

## Dados

Os lançamentos e convênios ficam na máquina do usuário. Antes de instalar uma atualização pelo app, o MeuCaixa guarda uma cópia dos dados na pasta local de backups.

O backup completo também pode ser exportado e importado em **Dados e backup**.
